# 📱 Galaxy S26 Privacy Display

A sleek and modern interactive phone UI simulation inspired by Samsung Galaxy devices. This project built with **HTML, CSS and JavaScript** demonstrates a realistic privacy display effect with dynamic viewing angle interaction and smooth, responsive UI behavior.

---

## 🚀 Features  
- 📱 **Realistic smartphone UI** inspired by Galaxy design  
- 👀 **Dynamic privacy display effect** based on cursor movement  
- 🔔 **Interactive notification system**  
- 🎛️ **Mode switching** (Full Screen / Notification)  
- 🎨 **Smooth animations and transitions**  
- 📱 **Responsive layout** for all screen sizes
